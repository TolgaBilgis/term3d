# term3d

A small 3D software renderer written in C that draws directly to a terminal.

The project explores the fundamentals behind a rendering pipeline: vector and matrix math, camera transforms, perspective projection, rasterization, depth handling, and terminal output. The implementation is kept compact enough to follow while building toward an interactive renderer.

## Status

Early development. The renderer is being built incrementally from the math and terminal foundations upward.

## Planned features

- 3D vector and matrix operations
- camera and model transforms
- perspective projection
- terminal framebuffer output
- wireframe and triangle rasterization
- depth buffering
- simple lighting and ASCII shading
- keyboard controls and animation
- OBJ mesh loading

## Building

The project targets a standard C toolchain on Linux and macOS. Build instructions will be added alongside the initial source and build system.
